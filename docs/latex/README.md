# GQ Atlas user guide and methods

Open the source as an Overleaf project by uploading this directory as a ZIP and selecting **gq-atlas-guide.tex** as the main document. Use pdfLaTeX or XeLaTeX.

To compile from this directory:

    latexmk -pdf gq-atlas-guide.tex

Or use Tectonic:

    tectonic gq-atlas-guide.tex

Keep the figures directory beside the main document. It contains the high-resolution screenshots, the editable TikZ flowcharts, and the original team flowcharts for reference.
